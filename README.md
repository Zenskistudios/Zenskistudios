## 🚀 About Me

- 🎓 Mathematics undergraduate at Lagos State University
- 💻 Full-stack developer since 2022: started frontend-first (React, Next.js), then moved into backend, Web3/Solana and systems programming
- 🌍 I build products tailored to Nigerian and African market realities
- 🌱 Currently learning **Rust and distributed systems**
- 💬 Ask me about **React, Next.js, Node.js, API design and Solana**
- 🎮 Online gaming and anime keep me sane; I enjoy solitude and deep-focus work
